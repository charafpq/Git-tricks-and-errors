Going Back in Time




//Temporarily Inspect an Older Version (Safe Read-Only Mode)




//To view your code as it was at a specific commit without deleting anything:
Bash

git checkout <commit-hash>

[[[]]][][][] To return to your latest code afterward, run: git switch main


Permanently Undo Recent Commits (Keep Changes in Workspace)

//To remove recent commits from Git history but keep all modified files intact on your computer:

git reset --soft <commit-hash>




//Permanently Delete Commits and Files (Destructive Reset)

To completely throw away all commits and local file changes after a specific point:
Bash

git reset --hard <commit-hash>



Syncing Changes with GitHub After a Reset

If you reset your local history (using --soft or --hard) and want to overwrite the remote history on GitHub:

git push origin main --force
